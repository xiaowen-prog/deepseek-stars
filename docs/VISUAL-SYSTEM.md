# 深度求索 · 统一视觉规范（V14）

适用范围：开场、十二幕、菜单、人物卡片、交互按钮与终章。本版本在 xiaowen-prog/deepseek-stars 的 main 公开源码上修改，未覆盖旧本地 V13。

## 视觉原则
深海黑底、蓝灰主体、少量暖光。文字清楚，场景有空间感。氛围不影响正文阅读。只在焦点节点和开场使用适度辉光，不把泛光、色差或噪声叠满全屏。

## 字体与排版
中文标题和叙事短句用 Noto Serif SC；正文和按钮用 Noto Sans SC；年份索引、深度和编号用 JetBrains Mono。字体本地加载。

桌面：年份48–64px，章节标题24px，叙事短句18px，正文15px/1.8，来源11px/1.7。手机：年份42px，标题22px，短句16px/1.75，正文14px/1.8。正文不使用300极细字重，不加发光阴影，不横向拉伸。

正文卡片不受手电筒遮罩影响。来源是次要信息，但不能降低到看不清。保持可滚动区域，避免小屏裁掉交互。

## 间距与组件
采用4px基准：4/8/12/16/24/32px。桌面卡片24px内边距，手机18px。统一6px圆角、1px边框，阴影0 12px 32px #02061140。卡片关闭背景模糊，使用足够不透明的底色。标题与正文14–20px，正文与来源12–16px，交互区独立分隔线。

按钮最小高42px；常规文字12px；使用蓝灰边框和轻微高亮反馈。聚焦轮廓2px浅蓝，偏移3px。交互不依赖只有鼠标悬停才能理解。

## 场景线条与光效
规则：装饰线弱于信息线，信息线弱于当前活动路径。细线在实际电脑尺寸至少能辨识；不要用大量发光叠加代替路径层级。尽量使用几何管线表示需要宽度的主线，不依赖WebGL原生线宽。

静止阅读期间不使用持续边缘色差。全屏DOM颗粒透明度0.045，着色器颗粒幅度0.003，日常抖动0；泛光强度0.22、半径0.18、阈值0.85。深度雾染色降至0.06。开场可以更强，但不得让正文和输入文字拖影。

## 清晰度与性能
桌面像素比例上限2，手机1.75。主场景离屏目标开启MSAA（桌面4采样、手机2采样），最终直接渲染场景启用抗锯齿。慢帧降级不再降低到0.75；在高分屏上保留较高分辨率。后台、开场、超过120ms的中断不参与平均帧耗时降级。

聊天画布2048×1440，在逻辑1024×720坐标绘制，保留原时序与场景结构。纹理各向异性4，文字不受色调映射压暗。

## 验证与交接
启动：python3 -m http.server 4185；浏览器打开 http://127.0.0.1:4185/?skip#y1986 。?replay播放开场。

在桌面和手机实际检查正文、人物卡片、聊天、第37手与终章。比较清晰度时使用同一浏览器尺寸，不把动画帧差异当作视觉回归。低端真机性能需要单独测试。
